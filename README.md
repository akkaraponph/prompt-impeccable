# Impeccable UX/UI Prompt Collection

A modular collection of 35 targeted UX/UI prompts designed to eliminate AI-generated sloppiness, enforce design system consistency, and elevate web applications to production-grade craftsmanship.

Each prompt is stored in its own standalone markdown file under this directory, ready to be used individually or combined for specific design, refactoring, and code review purposes.

---

## 🎯 Categorized by Purpose

### 1. General Polish & AI-Slop Elimination
Targeted prompts to eliminate common AI design tropes (excessive containers, decorative gradients, random badges) and restore visual discipline.

* [`01-base-production-polish.md`](./vibe-collections/01-base-production-polish.md) — Base production polish for hierarchy, spacing, alignment, and responsiveness.
* [`02-reduce-ai-sloppy-ui.md`](./vibe-collections/02-reduce-ai-sloppy-ui.md) — Audit and remove cards-inside-cards, excessive pills, badges, and decorative noise.
* [`03-icon-discipline.md`](./vibe-collections/03-icon-discipline.md) — Retain functional navigation/action icons while purging decorative clutter.
* [`04-visual-hierarchy-audit.md`](./vibe-collections/04-visual-hierarchy-audit.md) — Establish clear primary vs secondary visual emphasis and contrast.
* [`05-information-density-optimization.md`](./vibe-collections/05-information-density-optimization.md) — Maximize information value while lowering visual noise.
* [`30-ai-slop-detection-pass.md`](./vibe-collections/30-ai-slop-detection-pass.md) — Dedicated sweep for sparkle icons, decorative gradients, floating cards, etc.
* [`31-reduce-ui-noise.md`](./vibe-collections/31-reduce-ui-noise.md) — Reduce overall visual noise by 20–30% without removing features.
* [`32-improve-scanability.md`](./vibe-collections/32-improve-scanability.md) — Structure layouts for quick visual scanning within seconds.

### 2. Layout, Structure & Typography
Prompts focused on structural rhythm, container hygiene, and typographic hierarchy.

* [`06-card-reduction.md`](./vibe-collections/06-card-reduction.md) — Flatten unnecessary card wrappers into clean rows, lists, or whitespace.
* [`07-typography-refinement.md`](./vibe-collections/07-typography-refinement.md) — Establish clear typographic hierarchy and normalize sizing/weights.
* [`08-spacing-audit.md`](./vibe-collections/08-spacing-audit.md) — Harmonize margins, paddings, and gaps using design system spacing scales.
* [`28-content-first-interface.md`](./vibe-collections/28-content-first-interface.md) — Elevate content readability over decorative application chrome.

### 3. Components & Navigation UX
Prompts for refining specific UI components, data presentations, and navigational bars.

* [`09-button-hierarchy.md`](./vibe-collections/09-button-hierarchy.md) — Establish distinct visual weights for primary, secondary, and tertiary actions.
* [`10-form-ux.md`](./vibe-collections/10-form-ux.md) — Field ordering, accessible labels, validation, and actionable error states.
* [`11-table-data-grid-ux.md`](./vibe-collections/11-table-data-grid-ux.md) — Column prioritization, row density, sorting, pagination, and scanning ease.
* [`12-dashboard-cleanup.md`](./vibe-collections/12-dashboard-cleanup.md) — Strip decorative metrics and focus on actionable operational data.
* [`13-sidebar-navigation.md`](./vibe-collections/13-sidebar-navigation.md) — Clean grouping, subtle active states, indentation, and hierarchy.
* [`14-header-toolbar-cleanup.md`](./vibe-collections/14-header-toolbar-cleanup.md) — Simplify top bars and prioritize high-frequency contextual actions.
* [`15-search-ux.md`](./vibe-collections/15-search-ux.md) — Discoverable search, keyboard shortcuts, input sizing, and result presentation.
* [`16-filter-ux.md`](./vibe-collections/16-filter-ux.md) — Intuitive filter controls, active state visibility, and easy reset flows.
* [`27-interaction-polish.md`](./vibe-collections/27-interaction-polish.md) — Purposeful micro-interactions, subtle hover/focus states, and meaningful transitions.

### 4. UI States & Feedback
Prompts ensuring edge cases and asynchronous lifecycle states feel solid and calm.

* [`17-empty-state.md`](./vibe-collections/17-empty-state.md) — Helpful, concise empty states with clear calls-to-action.
* [`18-loading-state.md`](./vibe-collections/18-loading-state.md) — Layout-stable skeletons and proportional loading indicators.
* [`19-error-state.md`](./vibe-collections/19-error-state.md) — Actionable error messages, severity scaling, and clear recovery paths.
* [`20-status-design.md`](./vibe-collections/20-status-design.md) — Restrained, consistent status indicators without sensory overload.

### 5. Responsiveness, Accessibility & System Consistency
Prompts for multi-device support, inclusive standards, and design system governance.

* [`21-responsive-design-audit.md`](./vibe-collections/21-responsive-design-audit.md) — Fluid layout reorganization across desktop, tablet, and mobile.
* [`22-mobile-ux.md`](./vibe-collections/22-mobile-ux.md) — Thumb ergonomics, touch target sizing, and vertical flow.
* [`23-accessibility-audit.md`](./vibe-collections/23-accessibility-audit.md) — Semantic HTML, keyboard navigation, focus rings, and contrast compliance.
* [`24-dark-mode-audit.md`](./vibe-collections/24-dark-mode-audit.md) — Surface contrast, dark mode depth, avoiding pure black/neon glows.
* [`25-design-system-consistency.md`](./vibe-collections/25-design-system-consistency.md) — Align component styles and tokens with the established system.
* [`26-component-simplification.md`](./vibe-collections/26-component-simplification.md) — Eliminate wrapper bloat, duplicate styling, and over-engineering.

### 6. Product Persona & Final Production Passes
Targeted passes for developer products, professional SaaS aesthetics, and pre-shipping sanity checks.

* [`29-professional-saas-audit.md`](./vibe-collections/29-professional-saas-audit.md) — Cultivate a restrained, trustworthy, mature SaaS interface.
* [`33-professional-developer-tool-ux.md`](./vibe-collections/33-professional-developer-tool-ux.md) — Optimize for engineer workflows, high information value, and speed.
* [`34-final-simplification-pass.md`](./vibe-collections/34-final-simplification-pass.md) — Pre-ship cleanup pass to strip non-essential visual elements.
* [`35-final-product-quality-pass.md`](./vibe-collections/35-final-product-quality-pass.md) — Comprehensive pre-production checklist for consistency and edge states.

## 🛠 Recommended Workflow Combos

Combine these prompts for common lifecycle workflows:

### Scenario A: De-Slopping a New AI-Generated Component
1. Run [`02-reduce-ai-sloppy-ui.md`](./vibe-collections/02-reduce-ai-sloppy-ui.md)
2. Run [`06-card-reduction.md`](./vibe-collections/06-card-reduction.md)
3. Run [`03-icon-discipline.md`](./vibe-collections/03-icon-discipline.md)
4. Run [`31-reduce-ui-noise.md`](./vibe-collections/31-reduce-ui-noise.md)

### Scenario B: Data Heavy View (Tables / Grids / Dashboards)
1. Run [`11-table-data-grid-ux.md`](./vibe-collections/11-table-data-grid-ux.md) or [`12-dashboard-cleanup.md`](./vibe-collections/12-dashboard-cleanup.md)
2. Run [`05-information-density-optimization.md`](./vibe-collections/05-information-density-optimization.md)
3. Run [`32-improve-scanability.md`](./vibe-collections/32-improve-scanability.md)
4. Run [`16-filter-ux.md`](./vibe-collections/16-filter-ux.md)

### Scenario C: Mobile & Accessibility Hardening
1. Run [`21-responsive-design-audit.md`](./vibe-collections/21-responsive-design-audit.md)
2. Run [`22-mobile-ux.md`](./vibe-collections/22-mobile-ux.md)
3. Run [`23-accessibility-audit.md`](./vibe-collections/23-accessibility-audit.md)
4. Run [`24-dark-mode-audit.md`](./vibe-collections/24-dark-mode-audit.md)

### Scenario D: Pre-Merge / Production Ship
1. Run [`25-design-system-consistency.md`](./vibe-collections/25-design-system-consistency.md)
2. Run [`34-final-simplification-pass.md`](./vibe-collections/34-final-simplification-pass.md)
3. Run [`35-final-product-quality-pass.md`](./vibe-collections/35-final-product-quality-pass.md)
