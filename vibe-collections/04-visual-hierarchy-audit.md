# Visual Hierarchy Audit

/impeccable

Improve the visual hierarchy of this interface.

Users should immediately understand:

1. where they are
2. what the primary content is
3. what action matters most
4. what information is secondary

Use typography, spacing, grouping, alignment, and contrast before adding containers or decoration.

Reduce competing visual emphasis.

Not everything should look equally important.

Primary content should dominate.

Secondary metadata should remain quiet.
