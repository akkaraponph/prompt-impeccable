# Typography Refinement

/impeccable

Refine typography across this interface.

Create a clear hierarchy between:

* page title
* section heading
* component title
* body content
* metadata
* helper text

Avoid oversized marketing-style typography unless this is a marketing surface.

Normalize:

* font size
* font weight
* line height
* text spacing
* muted text usage

Typography should carry much of the interface hierarchy.
