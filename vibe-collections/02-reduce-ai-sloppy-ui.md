# Reduce AI-Sloppy UI

/impeccable

Audit this interface for common AI-generated UI patterns and simplify them.

Reduce:

* excessive cards
* cards inside cards
* unnecessary icons
* unnecessary badges
* excessive pills
* giant headings
* excessive whitespace
* decorative gradients
* excessive shadows
* excessive rounded containers
* repeated metadata
* unnecessary helper text
* decorative visual elements without functional value

Do not remove useful functionality.

Do not replace unnecessary decoration with different decoration.

Prefer:

typography → spacing → alignment → subtle separators → containers → decoration

The interface should feel handcrafted, restrained, and intentional.
