# Button Hierarchy

/impeccable

Review every button and action on this interface.

Establish clear action hierarchy.

Primary actions should be obvious.

Secondary actions should have lower visual emphasis.

Tertiary actions should not compete with primary actions.

Avoid turning every action into a prominent button.

Reduce unnecessary icon + text combinations.

Use destructive styling only for genuinely destructive actions.

The interface should make the next action obvious without becoming visually aggressive.
