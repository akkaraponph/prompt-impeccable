# Responsive Design Audit

/impeccable

Review this interface across:

* desktop
* laptop
* tablet
* mobile

Do not simply shrink the desktop layout.

Reorganize content where necessary.

Reduce unnecessary chrome on smaller screens.

Prevent:

* horizontal overflow
* crowded toolbars
* tiny touch targets
* unreadable tables
* broken cards
* awkward wrapping

Keep important information and actions accessible.
