# Icon Discipline

/impeccable

Review icon usage across this interface.

Preserve icons that improve:

* navigation
* recognition
* actions
* status
* scanning

Remove icons that are:

* decorative
* repeated unnecessarily
* placed beside every heading
* placed beside normal metadata
* duplicating obvious text
* used only to fill space

Do not make the interface icon-free.

Reduce icon density rather than removing iconography entirely.

Functional icons should remain.

Decorative icons should disappear.
