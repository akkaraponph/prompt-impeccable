# Design System Consistency

/impeccable

Audit this interface against the existing product design system.

Find inconsistencies in:

* spacing
* typography
* colors
* radius
* shadows
* buttons
* inputs
* cards
* badges
* icons
* states

Reuse existing components and tokens wherever possible.

Do not introduce a new visual pattern when an existing pattern already solves the problem.

Reduce one-off styling.
