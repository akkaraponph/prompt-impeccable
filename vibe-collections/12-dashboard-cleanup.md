# Dashboard Cleanup

/impeccable

Refine this dashboard into a focused operational interface.

Reduce unnecessary dashboard decoration.

Not every metric needs:

* a large card
* an icon
* a trend arrow
* a colored background
* a chart

Prioritize the metrics that support actual decisions.

Group related metrics.

Reduce competing emphasis.

Make the dashboard answer:

What is happening?

What requires attention?

What should the user do next?
