# Table / Data Grid UX

/impeccable

Refine this table or data-heavy interface for fast scanning.

Prioritize:

* important columns
* alignment
* readable row density
* clear headers
* predictable actions
* useful filtering
* sorting
* pagination
* selection states

Reduce:

* icons in every cell
* excessive badges
* unnecessary borders
* oversized rows
* repeated information

Keep row actions visually secondary until needed.

Make large amounts of information easier to compare.
