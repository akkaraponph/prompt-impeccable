# AI-Slop Detection Pass

/impeccable

Perform a dedicated AI-slop audit.

Look for patterns commonly produced by generated frontend designs:

* sparkle icons
* excessive gradients
* gradient text
* giant hero typography inside normal application pages
* excessive rounded cards
* floating containers everywhere
* random icon boxes
* excessive badges
* decorative statistics
* repetitive card layouts
* unnecessary explanatory copy
* fake visual complexity
* unnecessary animations
* too many colors
* everything centered
* every section having a subtitle
* every action containing an icon

Remove or simplify these patterns unless they genuinely support the product.

Do not make the design boring.

Make it intentional.
